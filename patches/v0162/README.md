# Dream Pulse TTS v0.16.2 — четыре обученных тембровых модели

## Результат

В репозиторий добавлены **четыре набора реальных обученных весов**,
по одному для каждого авторского женского голоса:

| ID | Обучение | Частотная ошибка до → после |
| --- | ---: | ---: |
| `dream_ref_hello` | 420 шагов Adam | 4.602 → 1.802 dB |
| `dream_ref_calm` | 420 шагов Adam | 6.234 → 3.048 dB |
| `dream_ref_weather` | 420 шагов Adam | 5.396 → 3.236 dB |
| `dream_ref_long` | 420 шагов Adam | 8.888 → 6.540 dB |

Это **обучение тембра**, а не полное дообучение Silero или клонирование
личности голоса. Ошибка здесь — несоответствие спектра на отложенных
фрагментах *тех же записей*. Она не доказывает похожесть голоса на слух,
разборчивость или способность произносить неизвестные слова голосом автора.

Каждый JSON содержит 129 уникальных коэффициентов симметричного
257-коэффициентного FIR-фильтра. Подбирались PyTorch Adam с регуляризацией
по четырём отдельным исходным WAV. Android теперь выполняет эти веса прямо
на PCM16, который сгенерировала базовая модель Silero, без Python и без
отдельного приложения RuVoice.

**Исходная модель Silero `v5_5_ru` не дообучалась**: она экспортирована
только для исполнения TorchScript Lite. Ни новые голоса, ни Ирина не
считаются готовыми полноценными TTS-голосами.

## Где находятся веса

```
patches/v0162/voice_weights/
  dream_ref_hello.json
  dream_ref_calm.json
  dream_ref_weather.json
  dream_ref_long.json
```

После применения Android-патча они помещаются в
`android/app/src/main/assets/dream_pulse_tts/styles/`. Код применения:
`DreamPulseTrainedTimbre.kt`. Веса хранятся в APK и НЕ требуют загрузки
отдельно от приложения.

## Как проверить на Android

1. Установить экспериментальную APK v0.16.2.
2. В настройках голоса сначала импортировать **Silero Full Lite ZIP**
   с оригинальными базовыми весами. Файл не включён в APK.
3. Выбрать один из четырёх авторских голосовых профилей.
4. Нажать **«Прослушать обученный тембр выбранного голоса»**.
5. Dream Pulse воспроизведёт короткую фразу, сформированную базовым Silero
   и обработанную соответствующими обученными коэффициентами.

**Это тест тембра.** Нельзя считать его точной копией исходного голоса.
Для полноценной речи нужны качественные расшифровки, отдельная
speaker-conditioned модель либо нейросетевое преобразование тембра, больше
чистых аудиозаписей и проверка качества на неиспользовавшихся фразах.

## Повторить обучение (без публикации аудио)

```sh
pip install torch numpy scipy soundfile
python3 patches/v0162/tools/fit_timbre_weights.py \
  --references /private/Dream-Pulse-PRIVATE-Voice-Dataset-v1.zip \
  --base-wav /private/silero_first_base_hello.wav \
  --output /private/weights
```

В GitHub находятся только обученные **малые коэффициенты** (параметры
тембра). Сырые аудиозаписи, фрагменты, расшифровки и личные данные
туда не загружались. При этом коэффициенты происходят из авторских
записей: это публичные производные акустические данные.

Ирина остаётся **пятым отдельным голосом**. В эту тренировку она не вошла:
её исходный обучающий материал не использовался.
